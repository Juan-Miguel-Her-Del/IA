# Datos, fuentes y reproducibilidad

- **TrashNet.** Se incluyen 2.390 fotos preparadas de cinco clases bajo MIT, con el aviso de Gary Thung y Mindy Yang en [TRASHNET_LICENSE.txt](TRASHNET_LICENSE.txt). La categoría `trash` quedó fuera del entrenamiento. [Ficha del dataset de los autores](https://huggingface.co/datasets/garythung/trashnet).
- **RealWaste.** Las fotos se obtienen del repositorio de los autores en una revisión fijada, o del ZIP UCI con `--archive`. UCI publica CC BY 4.0 y el README de los autores muestra CC BY-NC-SA 4.0. El paquete conserva manifiestos y hashes de A/B. Los clasificadores publicados funcionan con los checkpoints incluidos. [UCI](https://archive.ics.uci.edu/dataset/908/realwaste) · [Autores](https://github.com/sam-single/realwaste).
- **TACO.** Se incluye la anotación COCO oficial, acreditada a Pedro F. Proença y Pedro Simões (2020), y los manifiestos de Vision-IA. Las imágenes tienen condiciones individuales y se descargan desde los enlaces registrados. Si un enlace falla, el restaurador acepta `--taco-archive ruta/al/TACO.zip` como fuente adicional. El ZIP oficial de Zenodo es de unos 2,72 GB. La restauración comprueba SHA-256 y preserva el split histórico. [TACO oficial](https://github.com/pedropro/TACO) · [Archivo oficial](https://zenodo.org/records/3587843) · [Condiciones CC BY 4.0](https://creativecommons.org/licenses/by/4.0/).
- **MJU-Waste.** Se incluyen las anotaciones oficiales train/val y el manifiesto de las 636 fotos seleccionadas. El repositorio de código indica MIT. El permiso de redistribución de las fotos con personas en el archivo externo quedó sin confirmar. `scripts.download_mju` descarga el ZIP público de los autores (1,35 GiB) y verifica SHA-256. También acepta el mismo ZIP obtenido manualmente. [MJU-Waste oficial](https://github.com/realwecan/mju-waste#download).
- **FMD.** C2/C3 usan un suplemento histórico opcional. `python -m scripts.prepare_materials` recoge los materiales seleccionados del archivo público de MIT. Las fotos de FMD no forman parte del ZIP. [FMD oficial](https://people.csail.mit.edu/lavanya/fmd.html).

`data/reference` contiene manifiestos, anotaciones y huellas. `scripts.restore_public_data` recupera los archivos exactos, mantiene train/val y deja test reservado. Si un original cambió o dejó de estar disponible, el script informa qué filas quedan pendientes. Se puede volver a preparar un experimento separado con los scripts originales de importación y preparación. Las métricas históricas corresponden a los datos exactos identificados por sus manifiestos.

El archivo público MJU de los autores utiliza Google Drive como servidor de descarga. El script accede al enlace público, sin autenticación ni carpetas de tu cuenta. El flujo con TACO y clasificación B también funciona sin descargar MJU.
